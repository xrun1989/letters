# App Changelog

## v0.1 — prototype
- Added editable writing area.
- Added clickable word chips that open the lower analysis panel.
- Added basic local word/grammar hints and correction examples.
- Added warm paper and ink styling.
- Added GitHub Actions workflow to build and upload a debug APK artifact.
